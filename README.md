# SDL3 2D Game Project

Описание проекта
Данный проект представляет собой 2D-игру, написанную на языке C++ с использованием библиотеки SDL3.
В игре реализованы:
 1) перемещение персонажа;
 2) система диалогов;
 3) NPC;
 4) инвентарь;
 5) подбор предметов;
 6) система сохранения;
 7) пользовательский интерфейс;
 8) простая боевая система.
    
Используемые технологии
 1) C++
 2) SDL3
 3) SDL3_image
 4) SDL3_ttf

Основные возможности
 1) Игровой персонаж;
 2) перемещение;
 3) здоровье;
 4) анимации.

NPC
 1) диалоги;
 2) взаимодействие;
 3) враги.

Инвентарь
 1) хранение предметов;
 2) отображение интерфейса;
 3) сериализация.

Система сохранения
 1) сохранение прогресса;
 2) загрузка игры;
 3) бинарный формат.



Сборка проекта
Требования
Необходимо установить:
 1) SDL3
 2) SDL3_image
 3) SDL3_ttf
 4) Visual Studio

Сборка в Visual Studio
 1) Открыть проект.
 2) Подключить библиотеки SDL3.
 3) Собрать проект.
 4) Запустить приложение.

Управление
Клавиша: Действие E; Перемещение A/D; Атака F; Инвентарь I

Сохранения
Прогресс игры автоматически сохраняется в файл:
save.dat 

Особенности проекта
 1) модульная архитектура;
 2) использование ООП;
 3) работа с файлами;
 4) динамические структуры данных;
 5) система диалогов;
 6) система инвентаря.
